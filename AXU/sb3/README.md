# Directory Purpose
The .sb3 file is used for *Scratch v3*, which is the "language" most of the AXU's older code is in. It is basically just a .zip containing tons of image files and a single .json which contains the scripts.

You are supposed to open the AXU's .sb3 files in something called _TurboWarp_. If you load them with normal scratch you will have many bugs.
